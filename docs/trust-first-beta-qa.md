# Trust-first beta QA checklist

Run this checklist with local fixtures only. Do not trigger a live Keenable request.

## Acquisition workflow

- [ ] Scout retains discovered listings after refresh and clears them only on a new search.
- [ ] Analyze, Contact, Financial Estimates, Documents & Contract, Education, and How It Works highlight only the active left-navigation item.
- [ ] Every deal has one investor-facing status and one prioritised next action.
- [ ] Rejected cards show the existing rejection reason without changing the decision.

## Evidence and financial review

- [ ] Deal Score opens five clear score drivers.
- [ ] Evidence confidence explains data quality without implying investment quality.
- [ ] Missing rent, energy, build-year, or valuation evidence is clearly marked as needing confirmation.
- [ ] Financial facts are read-only; assumptions remain editable and resettable.
- [ ] The financial reminder remains bold, red, and readable.

## Documents and comparison

- [ ] Documents are visible only for deals explicitly moved into Document & Contract.
- [ ] Critical documents, financing documents, listing diligence, and received items are distinct.
- [ ] Filename matching is treated as a suggestion; manual confirmation is possible.
- [ ] Review output separates matching facts, clarification gaps, and contract questions.
- [ ] The non-legal-advice notice is visible.
- [ ] Comparison clearly marks unavailable evidence as needing confirmation.
- [ ] Print deal summary shows the selected deal without workspace controls.

## Accessibility and responsive checks

- [ ] At 1280px, 1024px, 768px, and 390px, no card content overflows its container.
- [ ] Keyboard focus is visible on navigation, actions, cards, and learning tiles.
- [ ] All action labels describe their outcome.
