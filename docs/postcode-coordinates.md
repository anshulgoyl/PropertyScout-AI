# German postcode coordinates

`data/postcode_coordinates.csv` contains German postcode centroids used solely
to order nearby-postcode discovery expansion. It must not be used as a
property-level location or valuation measurement.

Source: Markus Konrad / WZB Social Science Center, `plz_geocoord`, January
2019. The source data is available at
https://github.com/WZBSocialScienceCenter/plz_geocoord and is licensed under
Apache License 2.0.
